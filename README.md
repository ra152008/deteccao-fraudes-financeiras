## deteccao-fraudes-financeiras

## Objetivo

Desenvolver e avaliar modelos capazes de classificar transações realizadas com cartão de crédito como legítimas ou fraudulentas. O projeto também busca analisar os dados e comparar o desempenho dos modelos utilizando métricas adequadas para bases desbalanceadas.

## Base de dados

O projeto utiliza a base **Credit Card Fraud Detection**, disponibilizada no Kaggle pelo Machine Learning Group da ULB.

A base contém 284.807 transações, sendo 492 fraudulentas. Essa diferença entre as classes é um dos principais desafios considerados durante a análise e a avaliação dos modelos.

[Consultar a base de dados no Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

## Organização do projeto

O desenvolvimento está dividido em ciclos, cada um responsável por uma etapa do projeto.

- **Ciclo 1:** apresentação e reconhecimento da base de dados.
- **Ciclo 2:** carregamento, preparação dos dados e análise exploratória.
- **Ciclo 3:** Treino, teste e métricas.
- **Ciclo 4:** Revisão, análise de erros e checkpoint.
- **Ciclo 5:** Documentação e apresentação.
- **Ciclo 6:** Revisão cruzada, ensaio e entrega.

## Estrutura do repositório

- `docs/`: documentos e registros relacionados ao projeto.
- `notebooks/`: notebooks utilizados nas análises e no desenvolvimento dos modelos.
