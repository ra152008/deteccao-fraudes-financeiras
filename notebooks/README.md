
# Notebooks

Nesta pasta estão os notebooks utilizados durante o desenvolvimento do projeto, organizados por ciclo.

## Ciclos

- `ciclo-1.ipynb`: atividades de reconhecimento e análise inicial da base de dados.
- `ciclo-2.ipynb`: carregamento, preparação e análise exploratória dos dados.

Os notebooks são desenvolvidos no Google Colab e disponibilizados neste repositório para consulta e reprodução das etapas.
